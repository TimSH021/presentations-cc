# Visual QA

## Mechanical Verification
- [ ] PPTX exists and is non-empty
- [ ] Expected slide count: ___
- [ ] Rendered preview count matches
- [ ] Layout check passed (check_layout.py)

## Contact Sheet Review
- [ ] Does the deck look like one coherent presentation?
- [ ] Any slides look like a different template?
- [ ] Which slides are weaker than the rest?
- [ ] Important text blocks have enough space and hierarchy?

## Structured Visual QA
- [ ] Connected series continuous through intended markers
- [ ] Bars/dots/labels aligned to same axis logic
- [ ] Connectors attach to correct source/target
- [ ] Arrow directionality meaningful and consistent
- [ ] No floating slashes, detached strokes, pseudo-arrows
- [ ] Box systems reflect real grouping; equal-role boxes aligned
- [ ] Labels attached to the mark/connector/container they describe
- [ ] Tables/matrices preserve row/column grammar at thumbnail size

## System Consistency
- [ ] Header / title tabs consistent
- [ ] Footer / source lines consistent
- [ ] Page markers consistent
- [ ] Logo / brand mark placement consistent
- [ ] Chart language consistent
- [ ] KPI / card language consistent
- [ ] Title casing consistent

## Taste Blockers
Look for: placeholder icons / broken arrows / rough bitmap crops / weak brand marks / mixed title-tab geometry / footer drift / generic diagrams / floating connectors / cramped text / claim-support mismatch / unsupported claims
